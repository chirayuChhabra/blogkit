## Prerequisites

Ensure you have a Node.js or Bun environment set up.

## Scaffolding a New Project

The fastest way to start is to use our built-in CLI to scaffold a new project. 

```bash
bunx mr-md init
```

### What does `init` do?
It will automatically set up the recommended folder structure, including a sample chapter and lesson.

## Running the Development Server
To see your lesson live in the browser, run the development server from the root of your project:

```bash
bun run dev
```
